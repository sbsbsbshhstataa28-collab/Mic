# Rexxy Voice Relay — Android

This project is an Android voice-relay foundation: microphone capture, foreground service, realtime DSP presets, Telegram account/chat UI, and a clean boundary for Telegram MTProto + tgcalls.

## Important
Telegram group calls are not exposed through the ordinary Bot API. A user account must join the group call using MTProto `phone.joinGroupCall`, and Telegram requires the join `params` generated by the local tgcalls/WebRTC engine. See:
- https://core.telegram.org/method/phone.joinGroupCall
- https://github.com/TelegramMessenger/tgcalls
- https://github.com/tdlib/td

The `NativeTelegramRelayEngine` in this starter project is intentionally a stub. It prevents the project from pretending that a normal Android AudioRecord stream is already connected to Telegram. The final production build needs the native tgcalls + MTProto/TDLib adapter wired to `sendPcm()`.

## Build on GitHub Actions

1. Upload this folder to a GitHub repository.
2. Push the included `.github/workflows/build.yml`.
3. Open Actions → Build APK → Run workflow.
4. Download the generated `app-debug` artifact.

## DSP

The app includes realtime PCM processing and presets based on the supplied Rexxy Voice Pro feature set: Bass 400, Boss Voice, Echo God, Crystal, gain/drive and echo. Exact browser WebAudio behavior cannot be bit-for-bit identical on Android; the DSP is implemented natively for low-latency capture.
